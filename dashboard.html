📁 New Workflow — No More Freezing

  1. Put photos in your site/photos/ folder on your Mac
  2. Manage Photos → type each filename → pick categories → save
  3. Publish → downloads portfolio-data.json automatically
  4. Move the JSON to your site folder → GitHub Desktop → Commit → Push
  5. Cloudflare rebuilds and photos appear live in ~60 seconds ✓
